## 🚀 Sobre o Projeto
O **HMatrix** é uma ferramenta interativa em Shell Script pura projetada para Termux, Linux e Windows. Inspirada nos clássicos visuais de terminal, ela traz um conceito moderno de matriz esférica concêntrica no centro da tela, combinada com controles em tempo real, efeitos sonoros nativos e o carismático **Cachorro Hacker**!

✨ *Desenvolvido com dedicação para quem curte personalização de terminal e efeitos visuais imersivos.*

## 🎮 Funcionalidades e Controles

* **Esfera Matrix Concêntrica:** Animação fluida de expansão e contração direto do núcleo do terminal.
* **Modo Explosão (ON/OFF):** Toque na tela ou aperte qualquer tecla para alternar o modo de partículas explosivas com som nativo do terminal (`\a`).
* **Mudança de Cores Dinâmica:** Alterne a paleta de cores apertando teclas diferentes ou utilizando o teclado interativo.
* **O Cão Hacker Gigante (Ciclos 1/5 a 5/5):** A cada 5 ciclos completos, o sistema aciona o alerta máximo com o Cão Hacker em ASCII Art de alta definição e uma mensagem bilíngue especial de 30 segundos!

## 📥 Instalação Rápida

Clone o repositório e execute o script diretamente no seu terminal:

```bash
# Clone o repositório
git clone [(https://github.com/HLSV/HMATRIX)](https://github.com/HLSV/HMATRIX.git))

# Entre na pasta
cd HMatrix

# Conceda permissão de execução
chmod +x HMatrix

# Execute com o tutorial interativo
./HMatrix

# Ou execute direto na animação (pulando o tutorial)
./HMatrix DT
